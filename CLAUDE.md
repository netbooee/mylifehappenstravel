# Notes for Claude

- After committing and pushing work on a branch, open a pull request into `main` without asking first.
  Tony & Sharon asked for this so finished trips can go live by merging.

  `python3 tools/build.py` and commit the generated files in `site/` too.
- Keep private details (family names, texts, emails, where tickets are stored) out of the published pages.
